⌂ Wszystkie zadania
Osiem zadań z algorytmiki, przepisanych od nowa w Go (stdlib, bez zależności zewnętrznych). Obliczenia ciężkie (szukanie Armstronga do 10¹², sito do 10⁸, atak na Gronsfelda) działają jako joby tła z postęgiem odpytywanym przez API JSON. Frontend: vanilla JS + SVG — zero build, całość wbudowana w jeden binarny plik Go.
