# actors

* [Examiner (task author)](/actors/examiner.md) - The author of the exercise statements; their wording is the acceptance authority for each task domain.
* [Learner](/actors/learner.md) - A person working through the exercises: supplies inputs, watches results and progress, cancels work they no longer want.
* [Maintainer / auditor](/actors/maintainer.md) - The person (or agent) who changes the code and is accountable for the documented claims staying true; runs the quality gate.
