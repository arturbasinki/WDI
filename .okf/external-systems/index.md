# external-systems

* [Browser runtime](/external-systems/browser-runtime.md) - The client-side execution environment that renders the single-page frontend, performs routing, polls jobs, and owns all UI state.
* [Hosted CI runner](/external-systems/ci-runner.md) - The hosted pipeline environment that enforces the project's declared quality bar on every push and pull request.
* [Container platform](/external-systems/container-platform.md) - The container engine and base images used to build and run the product; recommended deployment target, not a code dependency.
