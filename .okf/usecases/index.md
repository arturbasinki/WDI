# usecases

* [Benchmark the sieve](/usecases/benchmark-sieve.md) - Run a cancellable benchmark of three sieve structures over chosen ranges, poll per-measurement progress, and receive the comparison table.
* [Break the cipher](/usecases/break-cipher.md) - Run a cancellable dictionary attack against a Gronsfeld ciphertext, poll keys-tried progress, and receive the key, plaintext, keys tried and cap status.
* [Browse the task catalog](/usecases/browse-task-catalog.md) - The learner lists the eight tasks from the server-side catalog and opens one; the client stores no task titles.
* [Encipher / decipher text](/usecases/cipher-text.md) - Encipher or decipher text with a digit key over the 27-symbol alphabet, reporting any characters normalization dropped.
* [Count top words](/usecases/count-top-words.md) - Request the top-N word ranking of the embedded canonical text or of a submitted text, with the applied N echoed back.
* [Generate a sudoku puzzle](/usecases/generate-sudoku.md) - Request a seeded sudoku puzzle generated by fill-then-dig so that it has exactly one solution, with the blank count reported.
* [Plot a function](/usecases/plot-function.md) - Submit an expression and interval, receive a segmented curve with asymptote positions and an applied clamp, with requested vs used sample counts disclosed.
* [Search narcissistic numbers](/usecases/search-armstrong-numbers.md) - Start a cancellable background search for narcissistic numbers up to a validated bound, poll its progress, and read the found numbers.
* [Solve a cryptarithm](/usecases/solve-cryptarithm.md) - Submit a cryptarithm equation and receive every solution's count with a capped list of mappings, the full count always reported.
* [Solve a linear system](/usecases/solve-linear-system.md) - Submit a linear system, get its classification, solution, RREF and the narrated elimination steps in one synchronous response.
* [Check / solve a sudoku grid](/usecases/solve-sudoku.md) - Submit a sudoku grid to count its solutions up to a cap and, on request, receive the first solution for display.
